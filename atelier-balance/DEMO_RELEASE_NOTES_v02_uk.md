# Atelier Balance · Pearl Glass — Demo 0.2

**Демореліз для Android від 16 листопада 2026 року.**

## Що нового після Demo 0.1
- Додано **18 додаткових страв** до каталогу: фаршировані перці, голубці, курячі рулетики, кабачкові човники, риба з овочами, запіканки, сирники та інші варіанти.
- У рецептах: ілюстративні фотографії, інгредієнти, час і покрокове приготування.
- Фільтри **«До 30 хв»** та **«Хочу щось цікаве»** для днів, коли є більше часу.
- Рекомендації за **галочками продуктів удома**: показують, що можна приготувати з наявного, та яких інгредієнтів бракує; додавання страв до сімейного меню.
- Оновлення залишає незмінними старі ключі локальних записів застосунку.

## Інші можливості
- Сімейне меню на **17–23 листопада 2026 року** з порціями для двох.
- Покупки, облік продуктів удома та сімейний бюджет.
- Орбітрек, вправи, тренер, маленькі завдання, винагороди й передбачення.
- Локальне збереження даних, їх резервне копіювання та можливість відновлення.
- Нагадування Android після надання дозволу.

## Установлення APK
1. Завантажити нижче в **Assets** файл `AtelierBalance-demo-v0.2.0.apk`.
2. На Android відкрити файл та дозволити встановлення з цього джерела за потреби.
3. Відкрити Atelier Balance і надати дозвіл на сповіщення, якщо потрібні нагадування.

## Увага при переході з Demo 0.1
Це **debug APK**, підписаний на сервері GitHub Actions. На різних запусках підпис може відрізнятися, тому **оновлення поверх Demo 0.1 може не встановитися**. Перед видаленням попередньої версії **експортуйте резервну копію** її даних та збережіть файл поза застосунком. Після встановлення нової версії можна імпортувати її назад (перенесення між різними WebView-сховищами не автоматичне).

## Статус
- Збірка перевірена GitHub Actions; Android-APK зібраний та перевірений як ZIP-архів.
- **Не протестовано на фізичному телефоні:** система нагадувань, резервне копіювання та поведінка після оновлення.
- Фото страв ілюстративні, каталог офлайн, **це не генеративний ШІ**.
- Це **preview/prerelease**, не медична система і не фінальний випуск для Google Play.
