# Atelier Balance · Pearl Glass Studio — Demo 0.6

**Оновлення каталогу продуктів: тепер не потрібно довго гортати перелік.**

## Нове
- **Помітне поле пошуку** у вкладці «Продукти»: введіть частину назви, наприклад `греч`, `молоко`, `яйце`.
- Відфільтровані результати з’являються **одразу під час введення**.
- **Швидкі категорії**: Основні, Усі, Маю вдома, М’ясо й риба, Овочі, Крупи, Молочне, Фрукти, Інше.
- На старті лише **10 найуживаніших продуктів**, а не нескінченний перелік. Кнопка «Показати всі продукти».
- Видимий лічильник результатів та вже відмічених продуктів.
- Галочки й кількість зберігаються у звичному сховищі; покупки продовжують враховувати їх.
- На головному екрані є кнопка **«Знайти продукт»**, яка відкриває пошук напряму.
- Для телефонів поліпшене оформлення карток і клавіатурного пошуку без подвійної кнопки очищення.

## Збережено
- Головне меню «Сніданок → Обід → Вечеря», вибір страв та фотографії.
- Базові порції для двох, їх редагування, нагадування.
- Автоматичні покупки, сімейний бюджет, вправи та мотивація.
- Офлайн-робота та звичні локальні ключі збереження даних.

## Як встановити
Виберіть `AtelierBalance-Studio-Search-demo-v0.6.0.apk` у розділі **Assets**, завантажте на Android (8.0+) і відкрийте файл.

## Увага щодо оновлення
APK підписано стандартним тимчасовим debug-ключем GitHub Actions, тому він **може не встановитися поверх Studio 0.5**, якщо підпис відрізняється. До видалення старої версії експортуйте резервну копію даних. Після перевстановлення відновіть її в застосунку. Встановлення поверх старої версії зі збереженням даних не гарантується.

Це **попередній тестовий реліз**. Збірку та JavaScript-сценарії перевірено автоматично, але на фізичному Android телефоні роботу ще потрібно перевірити.
