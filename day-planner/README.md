# Atelier Day · Pearl Glass — Demo 1.0

Окремий щоденник щоденних справ у стилі Pearl Glass для Android 8.0+.

## Функції

- Справи для кожного дня: дата, час, пріоритет, сфера життя, додаткова нотатка.
- Позначення виконання і кільце прогресу, календар місяця та огляд тижня.
- Повторення: щодня, у будні, щотижня, з окремими галочками на кожен день.
- Ритуали та відстеження послідовності виконання.
- Особисті нотатки й настрій на конкретну дату.
- Android-сповіщення про справи з часом: у зазначений час або за 5/15/30/60 хвилин, із відновленням планування після перезапуску телефона.
- Локальне збереження у WebView, без мережевих запитів і без акаунтів.
- Експорт JSON через системний вибір місця збереження та імпорт JSON із файла через системний вибір.
- Автономна HTML-версія (`app/src/main/assets/index.html`), де можна імпортувати резервну копію вставкою JSON, а сповіщення експортувати до календаря (.ics).

## Важливо

Користувач повинен один раз натиснути **«Увімкнути нагадування Android»** у налаштуваннях застосунку та дозволити сповіщення Android. Якщо у справи немає часу або вибрано «Без нагадування», сповіщення не створюється. Нагадування не є точними будильниками: через оптимізацію батареї система може їх затримувати.

Це **тестовий debug APK**, підписаний тимчасовим Android debug-сертифікатом GitHub Actions. Після наступної збірки підпис може бути іншим. Перш ніж видаляти цей APK, **експортуйте резервну копію** важливих справ; при перевстановленні всі локальні записи можуть зникнути.

Застосунок не вимагає INTERNET permission і не передає записів на сервер, але пристрій і його системні механізми резервування даних можуть мати власні політики.

## Збірка

GitHub Actions автоматично виконує `gradle --no-daemon -p day-planner assembleDebug` у гілці `atelier-daybook` та створює `AtelierDay-PearlGlass-demo-v1.0.0.apk` у GitHub Releases.

Для локальної збірки відкрийте цей проєкт в Android Studio, встановіть Android SDK 35 і Java 17 та виконайте `gradle assembleDebug`. Цей ZIP містить вихідний код; якщо `gradle` відсутній, установіть його або використайте GitHub Actions.

## Відомі обмеження

- Перевірено роботу основних екранів і локального збереження в Chromium; фонові нагадування треба перевірити на реальному Android.
- Ритуали не мають складних правил («кожного другого четверга»); доступні щодня, у будні, щотижня.
- Кожна повторювана справа має один шаблон; редагування шаблону змінює її майбутні повторення.
- Не синхронізує справи між телефонами без ручної резервної копії.
